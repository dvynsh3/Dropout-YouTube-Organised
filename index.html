Connect a YouTube API key

This tool matches Dropout's real show catalog to whatever's actually free on their YouTube channel, using a key tied to your own account so it's never rate-limited by anyone else's quota.

  1. Go to the Google Cloud Console → YouTube Data API v3 and click Enable (create a project first if asked).
  2. Open Credentials → Create credentials → API key.
  3. Paste that key below. It's stored only in this browser.
